# LinguaPath

Адаптивный учебный сервис для английского A1–C1 без регистрации и внешних API. Next.js App Router, TypeScript, React, Tailwind CSS и Lucide.

## Запуск

```bash
npm install
npm run dev
npm run typecheck
npm run build
npm start
```

Откройте http://localhost:3000. Node.js 20.9+ (рекомендуется актуальный LTS). Переменные окружения не нужны.

## Публикация на Vercel

Импортируйте репозиторий в Vercel, выберите Next.js и корневую директорию проекта. Команды установки и сборки определяются автоматически. Никаких секретов не требуется.

## Данные и ограничения

Данные находятся только в localStorage текущего браузера; они не синхронизируются. В настройках доступны экспорт, импорт формата версии 1 и сброс. Если хранилище недоступно, сайт предупреждает об этом. Речевой синтез и запись зависят от поддержки браузера и разрешения на микрофон.

Программа содержит по одному компактному уроку для каждого из четырёх модулей каждого уровня (20 уроков). Дополнительные темы в дорожной карте показывают план расширения, а не готовые уроки. Каждый урок содержит одно проверяемое упражнение; письменные и устные ответы оцениваются самостоятельно. Входной тест — краткий ориентир из пяти вопросов, не сертификат CEFR. Это начальная версия, а не полная замена преподавателю; отдельные контрольные тесты модулей, расширенный словарь, автоматическая проверка произношения и полноценные упражнения всех типов пока не реализованы.
